# Perpetual Falls: Google Play store listing

One folder per Play Console language (`play/<code>/`):
- `listing.json`: title, short description and full description
- `phone-01.jpg` … `phone-07.jpg` (1080 × 1920): phone screenshots with captions in that language and the game in that language
  (the game's own 21 languages; the other listing languages show the English game)
- `tablet-01.jpg` … `tablet-04.jpg` (2560 × 1600): 7-inch and 10-inch tablet screenshots, the game's 21 languages only
- `feature.jpg` (1024 × 500): the feature graphic

Made from the game's own 3D renderer. The source text lives in the Perpetualfalls repo under `store/`.
